# FOUNDRY

Send code from any AI web UI directly to VS Code.
Zero copy paste. Zero manual steps.

## What it does
- Adds ⚡ button to Kimi, DeepSeek, Claude, ChatGPT
- Click once — code lands in your active VS Code file
- Runs terminal commands and sends output back to AI
- AI sees the result and continues automatically

## Install
1. VS Code extension — press F5 in foundry-vscode
2. Chrome extension — load unpacked foundry-chrome

## Works with
- web.kimi.ai
- chat.deepseek.com
- claude.ai
- chatgpt.com
